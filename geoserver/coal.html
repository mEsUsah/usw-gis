Implementing GeoServer WMS

Legend

    GeoServer WMS

    The map demostrates the use of a dataset containing a set of polygons classified by feature types. These feature types are assigned a unique color using SLD styles created using QGIS that is helpful to quickly visually identify what resource is where on the map. The SLD style is used to build a legend for the map. The coal resources dataset was acquired from the British Geological Survey (link).

    The map legend is presented using the legend feature from the WMS service, and a modified version of the legend library from kartoza.
