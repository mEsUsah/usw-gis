Hiking in Norway

A map for planning hiking trips in Møre og Romsdal, Norway

Leaflet integration

The map above demonstrates demonstrates a map for planning short and long hiking trips. This map is the same that is used for printing hiking maps by the Norwegian Mapping Authority.

The map includes overlays for glaciers, avalanche risk, hiking trails that are color graded, and ski tours that are color graded, sourced from various Norwegian government WMS services.

It also features points of interest such as shelters and open cabins, and a hiking route that was sourced from the state sponsored hiking trip database morotur.no.

The map also includes a control that allows the user to center the map at their current location using the Geolet plugin for Leaflet.
